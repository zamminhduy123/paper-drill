Evidence

* conflicting papers: not stated.

* unknown: signal modality, uncertainty quantification, evaluation metrics, ground truth, dataset details, model architecture, latency, accuracy, privacy, and deployment constraints are unknown.

Transfer

* source field: smart classroom monitoring -> mechanism: TinyML on resource-constrained edge nodes for activity/learner-state detection -> IVN problem: in-vehicle network anomaly/behavior detection on constrained edge nodes.

* source field: adaptive learning response -> mechanism: responsive action from monitored state -> IVN problem: adaptive or responsive network/security action.

* source field: smart classroom deployment -> mechanism: real-world edge deployment -> IVN problem: vehicle deployment with different traffic, timing, and safety requirements.

* shift-or-failure condition: domain shift from classroom signals/objectives to IVN traffic, timing, and safety requirements; failure if false alarms/hour or detection delay exceeds IVN tolerance.
