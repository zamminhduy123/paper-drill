# A Development Methodology for Embedded Machine Learning (TinyML) Sensor-Based Systems: Phases, Checkpoints and the Role of Inference Location

Novelty

The work introduces a structured development methodology for embedded machine learning (TinyML) sensor-based systems, organized around distinct phases and checkpoints. A distinctive element is the explicit consideration of inference location as a design variable within the methodology. The supplementary material is oriented toward expert validation of the methodology, supporting the doctoral thesis of Alberto Gascón Roche at Universidad de Zaragoza.

Methodology

The methodology is described as phase-based with defined checkpoints, intended to guide the development of TinyML sensor-based systems. Inference location is treated as a component of the methodology, implying decisions about where inference executes within the system. Expert validation is used to assess the methodology, with the supplementary material serving as the instrument for that validation.

Explicit Limitations

Details of limitations are not stated in the provided material. The supplementary material is described only as accompanying the doctoral thesis and supporting expert validation.
