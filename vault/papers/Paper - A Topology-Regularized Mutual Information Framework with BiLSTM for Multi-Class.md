# A Topology-Regularized Mutual Information Framework with BiLSTM for Multi-Class Network Intrusion Detection

Novelty

The paper proposes a Topology-Regularized Mutual Information (TRMI) framework combined with Fuzzy Cognitive Maps (FCM) for feature selection, addressing the limitation of traditional MI-based methods that rank features independently and tend to select redundant features. FCM models features as interconnected nodes whose pairwise weights capture structural dependencies, reducing redundancy while retaining structurally significant traffic patterns. The TRMI-FCM selected features are then fed to a BiLSTM classifier for multi-class intrusion detection on the ALLFLOWMETER_HIKARI2021 dataset, achieving 0.995 accuracy and 0.989 F1-score, with improved robustness for uncommon attacks.

Methodology

The system comprises four unified stages: (1) Data Pre-processing — removing irrelevant attributes (flow IDs, IP addresses, port numbers), label encoding the categorical target traffic_category , z-score normalization, and stratified 80/20 train-test splitting to preserve minority class distribution; (2) Feature Analysis — statistical and visual techniques (box plots of feature values across traffic classes, group-wise feature correlation) across nine feature categories (flow behavior, packet statistics, payload, temporal patterns/IAT, protocol flags, subflow, activity, window size, header information); (3) Feature Selection (TRMI-FCM) — STEP-1 computes mutual information relevance scores MI_j between each feature X_j and the target Y, capturing linear and non-linear dependencies; FCM then models features as interconnected nodes with pairwise dependency weights to regularize the MI ranking against redundancy; (4) Classification — CNN, RNN, LSTM, DNN, and BiLSTM models trained on selected features, evaluated via accuracy, precision, recall, F1-score, class-wise analysis, and confusion matrix. TRMI-FCM is benchmarked against Random Forest (RF) and standard Mutual Information (MI) feature selection.

Explicit Limitations

The paper states that high-dimensional and imbalanced data such as ALLFLOWMETER_HIKARI2021 leads to poor classification and minority attack detection under existing ML/DL approaches. It notes that signature-based IDS are less effective against unknown and evolving attacks. The dataset itself is described as high-dimensional and imbalanced, with rare attack types (probing, brute force, cryptomining) making infrequent attacks difficult to detect. The literature review identifies challenges across prior work including dataset dependency and lack of standardized evaluation. The abstract positions the approach as improving robustness "especially for uncommon attacks," implying residual difficulty with minority classes. No explicit limitations section stating weaknesses of the proposed method itself is present in the provided text.
