# AI-Driven Cloud-Enabled Cybersecurity Framework for Intelligent IoT Intrusion Detection

## Novelty
Cloud-enabled cyber-physical IoT intrusion detection framework combining Sugeon-type fuzzy feature extraction with a table prior-based transformer classifier.

## Methodology
IoT signal data are preprocessed, features are extracted using Sugeon-type fuzzy feature extraction, and a table prior-based transformer-based intrusion detection system classifies the features in a cloud-based model.
