# An Adaptive and Intelligent Network Defense Framework for Real Time Cyber Threat Detection and Automated Response

## Novelty
Proposes an adaptive and intelligent NIDPS that integrates real-time traffic monitoring, feature extraction, supervised machine learning classification, and automated intrusion prevention; evaluates SVM, Random Forest, ANN, and XGBoost and reports that ensemble models perform best.

## Methodology
Uses benchmark intrusion detection datasets with preprocessing, feature selection, class imbalance handling, supervised machine learning classification, automated response, and evaluation of accuracy, precision, recall, F1-score, false positive rate, detection latency, and resource utilization.
