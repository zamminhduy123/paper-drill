# BusRecall: replication package for "Measuring source-vehicle forgetting in cross-vehicle CAN intrusion detection"

## Novelty
Replication package for measuring source-vehicle forgetting in cross-vehicle CAN intrusion detection, reproducing cross-vehicle collapse results, continual-learning comparisons across 24 task orders on two corpora, distillation-teacher diagnostics, and memory-budget curves.

## Methodology
Code and result files reproduce all paper tables and figures using public datasets: can-train-and-test and ORNL ROAD. The pipeline builds caches and evaluates cross-vehicle collapse with controls, continual-learning performance over task orders, distillation-teacher diagnostics on the target vehicle, and memory-budget behavior.

## Explicit Limitations
The two datasets are public and are not redistributed in the package; the README provides their DOIs and the pipeline for building caches.
