# HARDWARE-SOFTWARE CO-DESIGN OF MEMRISTIVE SYSTEMS FOR EDGE INTELLIGENCE

## Novelty
Hardware-software co-design of memristive analog in-memory computing systems for edge intelligence, spanning crossbar testing, hyperdimensional computing, RF signal processing, and cognitive radio receivers.

## Methodology
Develops a multichannel time-encoding testing system for memristive crossbars; implements hyperdimensional computing with a single-layer perceptron on a memristive SoC; builds an RF processing system with spectrum analysis, demodulation, and multilayer perceptron inference across memristive cores; implements a cognitive radio receiver using convolutional and fully connected neural networks.

## Explicit Limitations
not stated

## Future Work
Extend memristive co-design to broader applications, intelligent radio receivers, and next-generation edge intelligence.
