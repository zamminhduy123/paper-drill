# LUT-KAN: Look-up table acceleration of Kolmogorov–Arnold networks on resource-constrained microcontrollers for embedded edge inference

## Novelty
Introduces LUT-KAN, a look-up table acceleration method for Kolmogorov–Arnold networks targeting resource-constrained microcontrollers and embedded edge inference.

## Methodology
Accelerates Kolmogorov–Arnold network inference by using look-up tables on resource-constrained microcontrollers for embedded edge deployment.
