# Reconfigurable Ferroelectric Junction Field‐Effect Transistor for Input Masking Preprocessing in Efficient Neural Networks

## Novelty
A reconfigurable In2Se3/MoTe2 ferroelectric junction field-effect transistor is proposed for input masking preprocessing in efficient neural networks. It combines non-hysteretic logic operations with ferroelectric polarization switching to act as a controllable hetero-synapse and selectively mask redundant inputs.

## Methodology
The FeJFET modulates polarization degree and PN junction depletion region to realize reconfigurable input masking. A dual-FeJFET unit is constructed and validated in an industrial defect detection scenario using a spiking neural network, achieving 94.9% classification accuracy while halving computational overhead.
