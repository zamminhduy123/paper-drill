# SmartVille: A Framework for Realistic Deep Learning-Based Online Network Intrusion Detection

## Novelty
SmartVille is presented as a research framework for deep learning-based network intrusion detection under online, open-world, and multi-modal assumptions. Its novelty is not a single new detector, but a coherent blueprint that combines neural encoders, online learning, and collective anomaly detection within one end-to-end differentiable encode-process-decode structure.

## Methodology
The proposed approach uses an end-to-end differentiable encode-process-decode organisation. Neural encoders replace heavy manual feature engineering, online learning replaces static train-once evaluation, and supervised classification is studied alongside collective anomaly detection. The framework is intended to design, train, and benchmark adaptive intrusion detection models under realistic streaming, open-world, and multi-modal conditions.

## Explicit Limitations
The paper explicitly states that its main contribution is not a new stand-alone detection algorithm. It is a framework and research blueprint rather than a single deployed detector.

## Future Work
Future work implied by the abstract includes using the framework to analyse curriculum design, input-modality composition, and architectural choices for adaptive intrusion detection research. It also suggests benchmarking adaptive NID models under realistic online and open-world assumptions.
